# 🧀 Aper'wan — Apéritifs Locaux en Ligne

**Aper'wan** est une application de vente en ligne de planches apéritives et de produits locaux (saucisson, fromage, chips, vin, bières...).
Projet développé en React + Vite + Tailwind CSS.

## 🚀 Fonctionnalités prévues

- 🎨 Interface moderne avec React + Tailwind
- 📦 Catalogue de produits (saucissons, vins, fromages…)
- 🧩 Planches apéro fixes ou personnalisables
- 🛒 Système de panier & commande
- 👤 Espace utilisateur (connexion, inscription)
- 🔐 Authentification sécurisée (JWT)
- 📆 Produits du mois (édition limitée)
- 📱 Design responsive (mobile first)

## 🛠️ Stack technique

- **Frontend** : React, Vite, Tailwind CSS
- **Backend** : FastAPI ou Flask (à venir)
- **Base de données** : MySQL
- **Authentification** : JWT (à venir)
- **Déploiement** : GitHub + Vercel ou Render (à définir)

## ▶️ Lancer le projet

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev
```

Accès : [http://localhost:5173](http://localhost:5173)
